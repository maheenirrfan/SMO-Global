# My First Website

This project is a beginner-friendly static website built with HTML, CSS, and JavaScript.

## What is included

- `index.html` contains the page structure and content.
- `styles.css` contains the layout, colors, spacing, and responsive styling.
- `script.js` adds simple interactivity, including the mobile menu and scroll reveal effects.

## How to run it locally

1. Open a terminal in this folder.
2. Start a local web server:

   ```bash
   python -m http.server 8000
   ```

3. Open your browser and visit:

   http://localhost:8000

## Learning notes

- HTML gives the page structure.
- CSS controls the look and layout.
- JavaScript adds behavior such as menu toggling and animations.
- Responsive design makes the site work on phones, tablets, and desktop screens.

## Customizing the site

- Update the text in `index.html` to match your brand.
- Change colors, spacing, and typography in `styles.css`.
- Add more sections or features to expand the page.
